# keyglow

Companion app for the KeyGlow browser extension. It shows your Wordle progress on your physical RGB keyboard: green, yellow and red letter keys, just like the game's on-screen keyboard.

```
npx keyglow test   # check your keyboard: A green, B yellow, C red. Ctrl+C restores.
npx keyglow        # run while you play
```

Then install the browser extension and play. Setup, supported keyboards and options are in the [full README](https://github.com/aadilshaikh123/keyglow#readme).
